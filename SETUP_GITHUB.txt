CONFIGURAR EL ADMIN UNA SOLA VEZ
Necesitas un Fine-grained Personal Access Token de GitHub.

Recomendación de permisos:
- Repository access: Only select repositories
- Selecciona únicamente: ydg-client-portal
- Repository permissions:
  Contents: Read and write
- El resto puede quedarse sin permisos adicionales.

IMPORTANTE
NO escribas el token en ningún archivo.
El panel admin lo guarda únicamente en sessionStorage del navegador:
- dura durante la sesión/pestaña del navegador;
- no se publica en GitHub;
- no aparece en projects.json.

USO DIARIO
1. Entra en admin.html.
2. Conecta GitHub.
3. + NUEVO PROYECTO.
4. El ID YDG-xxx se genera automáticamente.
5. Añade cliente y enlaces Stripe.
6. Guardar.
7. Pulsa COPIAR ENLACE y se lo mandas al cliente.

PREVIEW
Al pasar a Preview, el sistema pide que exista la URL de preview.
El cliente seguirá usando siempre el mismo enlace.

STRIPE
En esta versión GitHub-only:
- los botones del cliente abren los Payment Links de Stripe que pegues en el proyecto;
- GitHub no puede verificar automáticamente que Stripe ha cobrado;
- después de recibir la confirmación de Stripe, pulsas el estado correspondiente en YDG Admin.
Eso son segundos y evita editar código manualmente.

SEGURIDAD
GitHub Pages es un sitio estático.
Un enlace project.html?project=YDG-001 NO es autenticación privada real.
No pongas datos personales sensibles, facturas, direcciones, tarjetas o documentación en projects.json.
Para privacidad real/Stripe automático más adelante hará falta backend.
